# Project Descriptions & Updates
 **COMALONG**<br>
 The objective of COMALONG is to use machine learning algorithms to detect extragalactic sources in multi-wavelength data. As a first step, X-ray data from e-ROSITA is used to compare the object detection of a large, pre-trained vision transformer vs a simple U-Net. Contrary to expectation, the U-Net performs better than the transformer. The next step is to understand why this occurs, and run tests with other datasets.

 **MERLIN**<br>
 Across subdisciplines, a lot of Astrophysical literature shares common concepts and methods, but may often refer to them with different labels. MERLIN falls under the umbrella of SUE, and it's goal is to build a representation space using diverse, multi-modal datasets in order to find similarities between them. The end product might be a search engine which can be used to explore this representation space. *Note: Project needs more Astrophysics expertise in order to understand what kind of data can be found, and how to handle the different datatypes.*
